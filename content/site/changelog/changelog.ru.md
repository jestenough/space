## v2.1.0

Дата: **2026.11.08**
- Добавлены изображения превью Open Graph и Twitter, включая сгенерированную карточку сайта
- Добавлена JSON-LD-разметка WebSite, Person и BlogPosting
- Добавлены локализованные RSS-ленты и ссылки на них в head и футере
- Изображения в sitemap оставлены внутри записей `<url>`; добавлена проверка разметки изображений

- Пустые разделы и тонкие страницы тегов исключены из sitemap и получили noindex
- Удалён постоянно присутствовавший клиентский блок ошибки и его неиспользуемые стили
- Добавлено обновление rel next/prev для клиентской пагинации
- Добавлена SVG-иконка сайта
- Усилена проверка вывода 404

## v2.0.0

Дата: **2026.11.06**
- HTML-слой переведён на Jinja2 с автоэкранированием и полноценными шаблонами страниц
- удалён regex-патчинг shell и собственный слой правки HTML
- `generated/` и `_headers` больше не публикуются; политика заголовков и кэша теперь только в nginx
- добавлены content-addressed кэши HTML, медиа и отрендеренных страниц с ограничением размера
- precompressed-ассеты переведены на gzip с `gzip_static`
- в deploy workflow добавлено кэширование слоёв Docker-образов
- добавлен preload ключевых font-сабсетов и transitions с поддержкой reduced motion
- объединена pre-paint логика темы и панелей; убраны анимации раскладки при загрузке и скачки шрифта
- уплотнён System Note
- `/` редиректится на `/en`, лишние `301` для directory-маршрутов убраны
- добавлены CSP, HSTS и проверка nginx-конфига
- добавлены unit-тесты для маршрутов, шаблонов, кэшей и инвариантов nginx
- исправлены локализованные raw-downloads для всех доступных языков
- статьи теперь требуют явную дату `date`

## v1.4.0

Дата: **2026.07.22**
- добавлены нумерованные интерактивные цитаты с явными диапазонами `\citetext{key}[location]{text}`, hover-подсветкой, переходом к источнику, открытием ссылок и копированием Reference в один клик
- добавлены строгие локализованные библиографии `references.<lang>.bib`, локализованное форматирование источников и preflight-проверки отсутствующих файлов, некорректных команд и неизвестных citation keys

- PDF приведён к паритету с HTML: локализованные авторы, citations и библиография, стабильный порядок нумерации, улучшенная диагностика компилятора и кеширование по content fingerprint
- добавлен локальный JetBrains Mono с Latin/Cyrillic subsets для terminal UI, Inter сохранён для читаемого текста статей
- frontend разделён на независимые actions, citations, clipboard и panels modules; stateful PageController заменён явной композицией `initPage()`
- исправлено перемещение панелей между mobile/desktop при изменении viewport, сокращены лишние listeners, DOM-операции, paint-эффекты и повторные build-time проходы по HTML
- улучшены responsive image variants, явные размеры изображений, cache headers для media/fonts, Docker source mounts и повторяемость prerender/PDF сборок
