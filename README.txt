Autophany space
===============

The Autophany space is a personal digital space.
Here you can learn about me, read my articles and notes,
follow my projects, and find other materials that I choose to publish.


Quick Start
-----------

Install:
  make install

Develop and preview:
  make dev

Production build:
  make build

Build and preview existing content:
  npm run dev

Docker:
  make docker-build-site
  make docker-preview
